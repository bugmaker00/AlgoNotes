# AlgoNotes

Licensing and metadata hub for the AlgoNotes dataset collection.

## Datasets

- **[AlgoNotes-Raw](https://huggingface.co/datasets/dongbobo/AlgoNotes-Raw)** – algorithm code snippets copied from `MathWeave/algobook-snippets` (upstream: `cc-by-4.0`).
- **[AlgoNotes-Explain](https://huggingface.co/datasets/dongbobo/AlgoNotes-Explain)** – synthetic explanations generated by `Qwen3-Coder` (model card: `apache-2.0`) built on top of AlgoNotes-Raw.

> **Note:** Mistral and Llama checkpoints listed in the repo were used only for exploratory experiments and did not produce any content included in the released datasets.
